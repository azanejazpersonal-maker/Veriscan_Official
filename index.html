      What Do These Checks Mean?

      1. Domain Information

      Examines how long a domain has been registered, expiration dates, and registrar credibility. Scams frequently use newly registered domains that are abandoned within weeks.

      2. HTTPS / Security

      Validates cryptographic encryption, modern TLS protocols, cipher suites, and Certificate Authority trust chains.

      3. Website Identity

      Inspects ownership alignment, brand trademarks, and typosquatting signals designed to imitate legitimate institutions.

      4. Business Information

      Cross-references corporate registries, tax filings, verified headquarters, and operational telephone contacts.

      5. Reputation Signals

      Queries threat intelligence databases, spam lists, community fraud reporting, and security telemetry.

      6. Suspicious Patterns

      Detects deceptive user interfaces, countdown timers, fake stock counters, and covert payment redirections.

      7. Trust Indicators

      Evaluates terms of service, clear privacy disclosures, return policies, and consumer protection guarantees.

      About VERISCAN

      What We Use to Analyze Websites

      VERISCAN combines multiple layers of factual network inspection and domain telemetry to provide objective security evidence:

      • Live Network Connectivity: Server-side probes that measure real-time HTTP reachability, status codes (200, 301, 404, etc.), latency, and TLS/HTTPS transport encryption.
      • SSRF & Internal IP Defense: Pre-request DNS resolution checks that block loopback (127.0.0.1), private subnets, cloud metadata (169.254.169.254), and non-routable addresses.
      • Safe Redirect Traversal: Follows redirect chains hop-by-hop up to 5 levels, re-validating security parameters before following any destination.
      • Authoritative RDAP Domain Registry: Directly queries RFC 9082/9083 RDAP endpoints across global TLD registries to retrieve authentic registrar identities and calculate exact domain age.
      • Threat Intelligence Telemetry: Integrates with VirusTotal API v3 to aggregate real security telemetry across 70+ global antivirus and domain reputation vendors.
      • Zero Client Payload Execution: Never runs target website JavaScript and never downloads large files.
